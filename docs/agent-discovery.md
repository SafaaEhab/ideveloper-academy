# Agent discovery resources

Canonical origin: `https://ideveloper-academy.vercel.app`

| Resource | Purpose |
|---|---|
| `/robots.txt` | Crawler policy, AI crawler groups, sitemap and agentmap |
| `/sitemap.xml` | Canonical public pages only |
| `/.well-known/api-catalog` | RFC 9727 Linkset for the public tRPC API |
| `/api.md` | Public tRPC API documentation |
| `/auth.md` | Accurate first-party authentication guide |
| `/.well-known/ai-catalog.json` | ARD manifest for real public resources |
| `/.well-known/agent-skills/index.json` | Two published public-site skills with SHA-256 digests |
| `/.well-known/agent-skills/*/SKILL.md` | Published skill artefacts |

Static discovery files are generated by `tools/generate-agent-discovery.mjs`
before each production build. `client/public` is copied to `dist/public`.

## Deliberately not published

- **Content-Signal** — omitted pending an owner licensing/content-use decision.
- **OAuth/OIDC discovery** — the app is a session-based OAuth *client* for
  optional Manus sign-in, not an authorization server. No fake token, JWKS,
  registration or protected-resource metadata is published.
- **MCP Server Card** — the app has no MCP server/transport. Ordinary tRPC routes
  are not relabelled as MCP.
- **DNS-AID** — the canonical host is a `vercel.app` subdomain whose DNS zone is
  controlled by Vercel, not this project. No DNS records are fabricated.

## Markdown negotiation

`Accept: text/markdown` requests for `/`, `/courses`, and `/register` are routed
to `/api/markdown`, which serves application-authored Markdown. HTML remains the
default. Private routes return 404 for Markdown.

## WebMCP

`client/src/lib/webmcp.ts` registers two progressive-enhancement tools when the
experimental WebMCP API exists: public course search and navigation to an
allow-listed public page. There are no authenticated or mutating tools.
